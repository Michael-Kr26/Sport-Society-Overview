# Sport Society Overview — V1.5 operationele release

## Doel

V1.5 maakt de huidige applicatie intern betrouwbaar en bruikbaar voordat nieuwe transactionele V2-modules worden gebouwd. De release verbetert eerst inzicht, datakwaliteit, navigatie, tests en beheerbaarheid.

## Definitief buiten scope

- salaris, loonstroken, payroll, cao-loonberekeningen en salarisexports;
- volledige boekhouding;
- automatische roosterbeslissingen op basis van voorspellingen;
- native mobiele apps;
- multi-tenant SaaS-functionaliteit.

## Geparkeerd

- `V2-PROFILE-01`: persoonlijk plus-/minurenoverzicht op het medewerkersprofiel. Uitvoering start uitsluitend na expliciete opdracht.

## Acceptatiecriteria V1.5

V1.5 mag pas als eerste interne release worden aangemerkt wanneer:

1. kritieke rooster-, uren- en toegangsflows een geautomatiseerde regressietest hebben;
2. alle rollen alleen hun toegestane informatie zien;
3. iedere import traceerbaar is naar bronbestand, tijdstip en resultaat;
4. datakwaliteitsproblemen centraal zichtbaar zijn;
5. de applicatie mobiel en desktop zonder blokkerende fouten werkt;
6. back-up en herstel aantoonbaar zijn getest;
7. changelog, versie en rollbackprocedure aanwezig zijn;
8. HealthPlanner- en bezoekersdata uitsluitend worden gebruikt volgens vastgelegde definities.
